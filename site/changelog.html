0.3.4 2026.10.27 LATEST

A patched Node.js, wakes that wait out a dialog instead of giving up, and file paths as chips. 패치된 Node, 대화상자에 막혀도 포기하지 않는 깨우기, 칩으로 보이는 파일 경로.

node Node Needs a patched Node.js, 22.23.4 or newer on 22 and 24.22.1 or newer on 24. With an older one the installer fetches pilo's own private Node instead and leaves yours alone. 패치된 Node 가 필요해요: 22 계열은 22.23.4 이상, 24 계열은 24.22.1 이상. 그보다 낮으면 설치 스크립트가 pilo 전용 Node 를 따로 받고, 원래 Node 는 그대로 둬요.
wakes 깨우기 A wake that hits a dialog tries again once the pane is idle, never backs off or gives up, and shows as wake waiting. Wakes to the desk go out as one bundle per tick and wait for a busy desk to finish, and the request says why it waits. 창에 대화상자가 떠서 못 깨운 경우 창이 한가해지면 다시 시도해요. 물러나거나 포기하지 않고, 상태는 깨우기 대기로 보여요. 데스크 깨우기는 한 번에 묶어 보내고, 데스크가 바쁘면 끝날 때까지 기다리며 왜 기다리는지 요청에 적혀요.
dashboard 대시보드 File paths in answers show as name chips that copy the whole path. A follow-up is recognised with a plain dash too, so its chip sits beside 'you', and a '1.' you wrote starts its own line. 답 속 파일 경로가 이름 칩으로 보이고, 누르면 전체 경로가 복사돼요. 일반 대시로 쓴 이어서 요청도 알아봐서 칩이 '나' 옆에 붙고, 직접 쓴 '1.' 은 새 줄에서 시작해요.
usage 사용량 The desktop app counts as a third usage source. Usage notes say in plain words what stopped updating, that it is not the usage limit, and what to do, at most once per reason every 12 hours. 데스크톱 앱이 세 번째 사용량 출처가 돼요. 사용량 알림은 무엇이 멈췄는지, 사용 한도 문제가 아니라는 것, 무엇을 하면 되는지 쉬운 말로 알려 주고, 같은 이유로는 12시간에 한 번만 떠요.
notes 알림 글 Notes the server writes for you are in Korean unless PILO_LANG says otherwise. 서버가 사용자에게 쓰는 알림 글은 PILO_LANG 으로 바꾸지 않으면 한국어예요.
0.3.3 2026.10.21

Schedules that run in a window, a schedule dialog that reads back as a sentence, and approval cards for subagents. 시간대 창으로 도는 예약, 문장으로 읽히는 예약 창, 하위 에이전트 승인 카드.

schedules 스케줄 A schedule can run in a window: every N minutes between two times, on chosen days. The schedule dialog asks two things, which days and then when, says the result back as a sentence with the next run, and greys out combinations that make no sense. 예약을 시간대 창으로 돌릴 수 있어요: 고른 요일, 두 시각 사이 N분마다. 예약 창은 요일과 시각 두 가지만 묻고, 결과를 다음 실행 시각과 함께 한 문장으로 보여줘요. 말이 안 되는 조합은 흐리게 막아요.
runs 실행 줄 A scheduled run shows its job's name with a grey mark and a schedule chip, folded or not, and a run that found nothing to change stays quiet. 예약 실행은 작업 이름과 회색 표시, 예약 칩으로 보여요(접혀 있어도). 바뀐 게 없는 실행은 조용히 넘어가요.
approvals 승인 Subagents asking at the same time each keep their own request, and the main agent finishing its turn no longer drops them. A numbered prompt no hook reported, such as Claude's own dangerous-command check, still becomes a card with its choices, and the agent shows as waiting on you instead of stalled. 하위 에이전트가 동시에 물어도 요청이 각자 남고, 메인 에이전트가 턴을 끝내도 지워지지 않아요. 훅이 알리지 않은 번호 선택 창(Claude 자체 위험 명령 확인 등)도 선택지 카드로 떠요. 이때 상태는 멈춤이 아니라 승인 대기.
dashboard 대시보드 The dashboard never reloads by itself: it offers a reload and keeps what you were typing. Models load in under two seconds with several Codex workers, and Models and Usage say what failed instead of always blaming an old server. One chip size everywhere. 대시보드가 스스로 새로고침하지 않아요. 새로고침을 제안하고 쓰던 글은 그대로 둬요. Codex 워커가 여럿이어도 모델 칸이 2초 안에 떠요. 모델·사용량 칸은 실패하면 항상 옛 서버 탓 대신 무엇이 실패했는지 보여줘요. 칩 크기 하나로 통일.
fixes 수정 The stalled-task nudge names its agent instead of a literal {agent}. 멈춘 작업 알림에 {agent} 글자 대신 에이전트 이름이 들어가요.
0.3.2 2026.10.20

Setup in the browser, an install that needs no Node, and approvals only for what matters. 설정은 브라우저에서, 설치는 Node 없이, 승인은 중요한 것만.

setup 설정 On a first run pilo opens the setup page in your browser: four steps that check themselves, from herdr and an agent session to the desk, the owners and a first request there and back. pilo --no-open keeps it in the terminal. 처음 실행하면 pilo 가 브라우저에 설정 화면을 열어요. herdr 와 에이전트 세션 확인부터 데스크, 담당, 첫 요청 왕복까지 스스로 확인하는 4단계. pilo --no-open 이면 터미널에만.
install 설치 No Node.js needed. Without Node 20 or newer, the curl installer gives pilo a private Node in ~/.pilo/runtime, checked against nodejs.org, and leaves yours alone. Node 가 없어도 돼요. Node 20 이상이 없으면 curl 설치가 pilo 전용 Node 를 ~/.pilo/runtime 에 받아요(nodejs.org 체크섬 확인). 원래 Node 는 그대로.
herdr herdr herdr is found where Homebrew puts it on Intel Macs too. herdr up with no agent pane says to open one, instead of saying herdr is not running. 인텔 맥의 Homebrew 경로에 깐 herdr 도 찾아요. herdr 는 켜졌는데 에이전트 창이 없으면 herdr 를 켜라는 대신 창을 열라고 안내해요.
approvals 승인 Pilo asks only before the very important things: a delete that cannot be undone, a database or cloud change, a force push over a shared branch, posting as you, a secret's value, a message to someone outside. Each is answered from the dashboard, the phone or the terminal UI with one confirm, and the card says in red what the command does. 아주 중요한 것만 물어요. 되돌릴 수 없는 삭제, DB·클라우드 변경, 공유 브랜치 강제 push, 사용자 이름으로 게시, 비밀 값, 회사 밖 메시지. 대시보드·폰·터미널 UI 에서 확인 한 번으로 답하고, 카드에 명령이 하는 일이 빨간 줄로 나와요.
cards 카드 Each approval card opens with the agent and the task it is on, then what the command does in your language, before the agent's own sentence. 승인 카드 맨 위에 어느 에이전트가 어느 작업 중에 묻는지, 그 아래 명령이 하는 일을 화면 언어로 보여 줘요. 에이전트가 쓴 문장은 그 아래.
secrets 비밀 Pilo asks about secrets only when a secret file is read or a value is printed. gh secret list and other name-only lookups go ahead. 비밀 파일을 읽거나 값을 출력할 때만 물어요. gh secret list 처럼 이름만 보는 조회는 그냥 진행해요.
codex codex With Approve for me on, Codex's own reviewer answers ordinary requests again, before Pilo is asked. Browser actions that can post as you (click, type, submit) still come to you as a card. Codex now stops on the same few important things and asks you through Pilo. Approve for me 를 켠 Codex 세션은 일반 요청을 Codex 자체 검토가 먼저 답해요. 내 계정으로 올릴 수 있는 브라우저 동작(클릭·입력·전송)은 계속 카드로 와요. Codex 도 같은 몇 가지 중요한 일에서 멈추고 Pilo 로 물어요.
temp files 임시 파일 rm -rf inside temporary folders (/tmp, $TMPDIR, ~/.cache) goes ahead without asking. 임시 폴더(/tmp, $TMPDIR, ~/.cache) 안의 rm -rf 는 묻지 않고 진행해요.
restarts 재시작 A session Pilo restarts comes back in your default permission mode, not in the one its conversation last had. Pilo 가 다시 띄운 세션은 대화가 마지막에 쓰던 모드가 아니라 기본 권한 모드로 돌아와요.
wake 깨우기 A wake is no longer typed into Claude's "new MCP servers" prompt, which took the answer for you, nor into an open settings screen such as /permissions: it waits and is sent again once the screen closes. Claude 의 'new MCP servers' 선택 화면에 깨우기 문장을 치지 않아요. 전에는 그게 답을 대신 눌렀어요. /permissions 같은 설정 화면이 열려 있으면 기다렸다가 닫힌 뒤 다시 보내요.
inbox 받은 요청 A request that was answered while work is still out is told apart from one that is finished. Work waiting on someone outside Pilo shows as holding, and a failure the answer already covered is no longer called a slip. 답은 했지만 일이 아직 남은 요청과 끝난 요청을 구분해요. Pilo 밖 사람을 기다리는 일은 보류로 보여 주고, 답에서 이미 다룬 실패는 누락으로 치지 않아요.
mac app 맥 앱 The installed app draws its own title bar, so the window behind no longer shows through it. 설치한 앱이 제목 표시줄을 직접 그려서 뒤 창이 비쳐 보이지 않아요.
arrows 화살표 <-> shows as ↔ on the dashboard, as -> and <- already did, and turns into ↔ as you type it. Code is left as written. 대시보드에서 <-> 가 ↔ 로 보여요(->, <- 처럼). 입력창에서도 치는 순간 ↔ 로 바뀌어요. 코드 안은 그대로.
language 언어 The dashboard starts in your browser's language until you pick one. 언어를 고르기 전에는 브라우저 언어로 시작해요.
0.3.0 2026.10.13

Installed with npm, and answers from the dashboard. npm 으로 설치하고, 대시보드에서 답해요.

install 설치 pilo is on npm: npm install -g @garamnohhh/pilo. The install line still works and now calls npm. pilo 를 npm 으로 설치해요: npm install -g @garamnohhh/pilo. 기존 설치 줄도 되고, 이제 npm 을 불러요.
updates 업데이트 an npm install updates from the npm registry — pilo update, or Install on the dashboard. A working copy is still told to use git. npm 설치본은 npm 레지스트리 기준으로 업데이트해요 — pilo update 나 대시보드의 설치 버튼. 작업용 저장소는 지금처럼 git 으로 하라고 안내해요.
approvals 승인 with pilo hooks install, a session's permission prompts and multiple-choice questions can be answered on the dashboard, the phone and the terminal UI as well as in its pane. rm -rf, force pushes, sudo, database writes and secrets stay pane-only. pilo hooks install 로 세션의 권한 요청과 선택지 질문을 창뿐 아니라 대시보드·폰·터미널 UI 에서도 답해요. rm -rf, 강제 push, sudo, DB 쓰기, 비밀 파일은 창에서만.
limits 한도 Claude's plan limits are read from the sessions themselves through a small mod, so the figure stays fresh without typing /usage anywhere. Claude 사용 한도를 세션이 직접 알려 줘요(작은 mod). /usage 를 칠 필요가 없어요.
sessions 세션 a wake is never typed into a dialog, and a restart resumes the exact conversation the pane reported. 대화상자가 떠 있는 창에는 깨우기를 넣지 않고, 재시작은 창이 알려 준 바로 그 대화로 이어 가요.
0.2.0 2026.10.07

The desk on a phone, updates from inside pilo, and a screen for usage. 폰에서 쓰는 창구, pilo 안에서 하는 업데이트, 사용량 화면.

phone 폰 the dashboard fits a phone: one screen at a time with a tab bar, and it can be added to the home screen. When the Mac does not answer, an offline screen shows the requests and answers the phone kept. 대시보드가 폰에 맞춰져요. 한 번에 한 화면, 아래쪽 탭으로 오가고 홈 화면에 앱으로 추가할 수 있어요. 맥이 응답하지 않으면 오프라인 화면에 폰에 남은 요청과 답이 보여요.
updates 업데이트 pilo looks once a day for a newer release and says so on the dashboard and the terminal UI. Install it from System, or run pilo update. The installer now installs the newest release instead of main. 하루 한 번 새 릴리스를 확인해 대시보드와 터미널 UI 에 알려요. System 화면에서 설치하거나 pilo update 를 실행하면 돼요. 설치 스크립트도 main 대신 최신 릴리스를 설치해요.
commands 명령 pilo start, pilo stop and pilo restart. up and serve still work. pilo start · pilo stop · pilo restart. up 과 serve 도 그대로 돼요.
usage 사용량 a usage screen: Claude and Codex five-hour and weekly figures, the last day on one chart, and today's tokens. When Claude's figure cannot refresh, it says why. 사용량 화면이 생겼어요. Claude·Codex 의 5시간·주간 수치, 하루 추이 그래프, 오늘 토큰. Claude 수치가 갱신되지 않으면 이유를 보여줘요.
agents 에이전트 a PM waiting on its worker counts as waiting, and is woken when the worker reports. Idle sessions can be restarted, and models picked, from the dashboard. 워커를 기다리는 담당은 '기다림'으로 보이고, 워커가 보고하면 깨워요. 쉬고 있는 세션 재시작과 모델 선택을 대시보드에서 할 수 있어요.
decisions 결정 a question is asked once, in the conversation it belongs to. 같은 질문은 한 번만, 그 대화 안에서 물어요.
0.1.0 2026.09.21

The first release. One desk in front of the agents you already run, on your own machine.첫 공개예요. 이미 띄워둔 에이전트 앞에 두는 창구 하나, 전부 내 컴퓨터에서 돌아요.

desk창구 one conversation for every project. The desk decides whose work a request is, hands it on, and writes back a single answer.프로젝트가 몇 개든 대화는 하나예요. 대표가 누구 일인지 정해 넘기고, 돌아온 걸 모아 한 번에 답해요.
agents에이전트 owners and specialists registered from the herdr panes you already opened. pilo starts none of them.이미 열어둔 herdr 창에서 담당과 분야 담당을 등록해요. pilo 가 띄우는 건 없어요.
trail기록 every request keeps its stages — what was said, who took it, what failed, what came back.요청마다 단계가 남아요 — 말한 것, 누가 맡았는지, 무엇이 실패했는지, 무엇이 돌아왔는지.
schedules예약 standing work on its own clock, and a run that is still open passes its slot.정해진 시각에 도는 일. 지난 회차가 안 끝났으면 그 차례는 건너뜁니다.
limits한도 a runtime that runs out is parked until it reopens, and its unopened queue goes to its owner.한도가 찬 런타임은 세워 두고, 열리지 않은 대기열은 담당에게 넘겨요.
local로컬 PGlite under ~/.pilo, one socket on 127.0.0.1, no account and nothing sent out.~/.pilo 안 PGlite, 127.0.0.1 소켓 하나. 계정도 없고 밖으로 나가는 것도 없어요.
