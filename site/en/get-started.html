GETTING STARTED

Getting started시작하기

Installed to a first answer, in seven steps.설치부터 첫 답까지, 일곱 단계예요.

Installed to a first answer. Each step says which screen you are on before it says what to type, and ends with what you should see. Numbered steps are the ones everybody walks; anything below a dashed line is only for when something is wrong.설치부터 첫 답까지예요. 단계마다 지금 어느 화면인지가 먼저 나오고, 그다음이 거기서 칠 것, 마지막이 무엇이 보이면 넘어가도 되는지예요. 번호가 붙은 것은 모두가 순서대로 밟는 것이고, 점선 아래는 안 될 때만 보는 곳이에요.

two screens: your terminal, then the setup page pilo opens in your browser화면은 둘이에요. 터미널, 그리고 pilo 가 브라우저에 여는 설정 화면

01terminal터미널Install설치
TERMINAL
$ curl -fsSL https://pilo.garamnoh.workers.dev/install.sh | sh
Installs the pilo command. No Node.js needed: with Node 20 or newer it is the plain npm install, and without it pilo gets a private Node in ~/.pilo/runtime (about 27 MB) that leaves yours alone.pilo 명령을 설치해요. Node 는 없어도 돼요. Node 20 이상이 있으면 그냥 npm 설치고, 없으면 pilo 전용 Node 를 ~/.pilo/runtime 에 받아요(약 27MB). 원래 쓰던 Node 는 건드리지 않아요.
you are through when되면
pilo --help prints the command list. You are still in the shell.pilo --help 가 명령 목록을 뱉어요. 화면은 아직 터미널 그대로.
if it says command not found안 되면 — command not found
~/.local/bin is not on your PATH. The installer prints the line to add.~/.local/bin 이 PATH 에 없는 거예요. 설치 스크립트가 넣을 줄을 그대로 알려줘요.
TERMINAL
$ export PATH="$HOME/.local/bin:$PATH"
02terminal → browser터미널 → 브라우저Run it: setup opens in your browser실행: 설정이 브라우저에서 열려요
TERMINAL
$ pilo
With no desk registered yet, pilo starts its server, opens the setup page in your browser and prints its address. The terminal UI shows the same address. pilo --no-open skips the browser.아직 데스크가 없으면 pilo 가 서버를 켜고 브라우저에 설정 화면을 열고 주소를 찍어 줘요. 터미널 화면에도 같은 주소가 나와요. 브라우저를 열기 싫으면 pilo --no-open.
you are through when되면
A browser tab is open on 127.0.0.1:48888/welcome with four steps.브라우저에 127.0.0.1:48888/welcome 이 열리고 단계 넷이 보여요.
if no browser opens안 되면 브라우저가 안 열릴 때
Open the address from the terminal yourself, or run pilo dashboard in another tab.터미널에 찍힌 주소를 직접 열거나, 다른 탭에서 pilo dashboard 를 실행해요.
03browser브라우저Get ready준비물
Node 20 or newer, herdr running, and a Claude Code or Codex session in a herdr pane. Each check turns green on its own; what is missing comes with the command to copy.Node 20 이상, herdr 실행, herdr 창 안의 Claude Code 나 Codex 세션. 확인되면 저절로 초록이 되고, 빠진 건 복사할 명령이 같이 나와요.
you are through when되면
All three checks are green and the step folds to one line.세 줄 모두 초록이 되고 단계가 한 줄로 접혀요.
if herdr is not running안 되면 herdr 가 꺼져 있을 때
TERMINAL
$ curl -fsSL https://herdr.dev/install.sh | sh $ herdr
if herdr is up but no session shows안 되면 herdr 는 켜졌는데 세션이 없을 때
Open a herdr pane in a project folder and start Claude Code or Codex in it. The page notices within a few seconds.프로젝트 폴더에서 herdr 창을 열고 Claude Code 나 Codex 를 실행해요. 몇 초 안에 화면이 알아채요.
TERMINAL
$ claude
04browser브라우저Pick your desk데스크 정하기
The desk is the one session you talk to. It reads every request and hands it to the right owner. Pick it from the sessions pilo found and press the button; pilo writes its instructions into that folder.데스크는 말을 거는 세션 하나예요. 요청을 모두 읽고 맞는 담당에게 넘겨요. 찾은 세션 중에 고르고 버튼을 누르면 그 폴더에 지시문을 써 줘요.
you are through when되면
The step folds to one line with the desk's folder.단계가 데스크 폴더 한 줄로 접혀요.
05browser브라우저Register the owners담당 등록
Each other session owns one project. Give it a name, look at the block pilo will write into that folder's CLAUDE.md or AGENTS.md with Preview, then Write and register. The agent reads it on its next turn. This step is optional.나머지 세션은 프로젝트 하나씩을 맡아요. 이름을 정하고 미리 보기로 그 폴더의 CLAUDE.md 나 AGENTS.md 에 쓸 내용을 본 뒤 쓰고 등록해요. agent 는 다음 차례에 읽어요. 건너뛰어도 돼요.
you are through when되면
Each owner shows as registered, or you skipped the step.담당마다 registered 가 붙거나, 단계를 건너뛰었어요.
to add one later나중에 추가하려면
agents → Add agent on the dashboard does the same for any session.대시보드 agents → Add agent 에서 어느 세션이든 같은 방법으로 등록해요.
06browser브라우저Send a first request첫 요청 보내 보기
One request there and back, to see that the desk hears you and answers. An example is filled in; send it as it is or write your own.요청 하나를 보내 데스크가 듣고 답하는지 확인해요. 예시 문장이 들어 있으니 그대로 보내도 되고 바꿔도 돼요.
you are through when되면
The desk answers, the page says You're set, and Go to the desk opens Work.데스크가 답하면 You're set 이 뜨고, Go to the desk 를 누르면 Work 화면으로 가요.
if there is no answer after two minutes안 되면 2분이 지나도 답이 없을 때
The desk's pane may be showing a prompt of its own, such as a trust or permission question. Answer it there and pilo carries on.데스크 창에 신뢰나 권한 같은 자체 질문이 떠 있을 수 있어요. 거기서 답하면 pilo 가 이어서 진행해요.
07the desk, either one데스크 — 어느 쪽이든Say one thing, get one answer요청 한 건 넣고 답 받기
Type it at the prompt. You do not name an agent: the desk reads the request, decides whose work it is, and hands it on. While it is out, the line under your request says who is holding it; when everything lands you get one answer, in the language you asked in.프롬프트에 그냥 적어요. 누구에게 시킬지 안 고릅니다 — 데스크가 읽고 누구 일인지 정해서 넘겨요. 일이 나가 있는 동안 요청 아래 줄에 누가 들고 있는지가 붙고, 다 들어오면 답이 하나로 와요. 물어본 언어로.
you are through when되면
One request, one answer — and requests keeps every stage it went through.요청 한 줄에 답 한 줄. requests 화면에 그 요청이 거쳐 간 단계가 남아 있어요.

The screens here are the real app against a demo desk — projects that do not exist and requests that never happened.이 문서의 화면은 실제 앱이고 데이터는 시연용이에요. 있지도 않은 프로젝트와 일어난 적 없는 요청입니다.

Everything else is in the나머지는 전부 docs문서에 있어요
