GETTING STARTED

Getting started시작하기

Installed to a first answer, in seven steps.설치부터 첫 답까지, 일곱 단계예요.

Installed to a first answer. Each step says which screen you are on before it says what to type, and ends with what you should see. Numbered steps are the ones everybody walks; anything below a dashed line is only for when something is wrong.설치부터 첫 답까지예요. 단계마다 지금 어느 화면인지가 먼저 나오고, 그다음이 거기서 칠 것, 마지막이 무엇이 보이면 넘어가도 되는지예요. 번호가 붙은 것은 모두가 순서대로 밟는 것이고, 점선 아래는 안 될 때만 보는 곳이에요.

two screens: your terminal for the install, then the pilo app for everything else화면은 둘이에요. 설치할 때 터미널, 나머지는 전부 pilo 앱

01terminal터미널Install설치
TERMINAL
$ curl -fsSL https://pilo.garamnoh.workers.dev/install.sh | sh
Puts the server in ~/.pilo/bin and the app in ~/Applications/pilo.app, starts both at login, adds Pilo's hooks to Claude Code (and Codex, if you have it) and adds ~/.local/bin to your shell's PATH for the pilo command. Nothing needs sudo, Node or anything else installed first. Or download pilo-<version>-mac.tar.gz from the latest release, unpack it and run ./pilo-<version>-mac/install.sh.서버는 ~/.pilo/bin, 앱은 ~/Applications/pilo.app 에 두고, 둘 다 로그인할 때 켜지게 해요. Claude Code(있으면 Codex 도)에 Pilo 훅을 넣고, pilo 명령을 쓰도록 ~/.local/bin 을 셸 PATH 에 넣어요. sudo 도, Node 도, 미리 깔 것도 없어요. 또는 최신 릴리스에서 pilo-<version>-mac.tar.gz 를 받아 풀고 ./pilo-<version>-mac/install.sh 를 실행해요.
you are through when되면
The installer finishes and the pilo app opens.설치가 끝나고 pilo 앱이 열려요.
if macOS refuses to open it안 되면 macOS 가 막을 때
The build is not notarised yet. Running the installer from a terminal, as above, is what keeps macOS from refusing it.아직 공증 전이에요. 위처럼 터미널에서 설치 스크립트를 실행해야 macOS 가 막지 않아요.
if it says command not found안 되면 command not found
~/.local/bin is not on this shell's PATH yet. Open a new terminal, or add it for this one:이 셸의 PATH 에 아직 ~/.local/bin 이 없는 거예요. 터미널을 새로 열거나, 지금 창에서 넣어요.
TERMINAL
$ export PATH="$HOME/.local/bin:$PATH"
02app앱Set up pilo opens in the app앱에서 Set up pilo 가 열려요
The installer opens the app on Set up pilo: four steps, each checking itself, so you can leave and come back. There is no browser page. Later, pilo in a terminal opens the app.설치 스크립트가 앱을 Set up pilo 화면으로 열어요. 단계는 넷이고 저마다 스스로 확인하니, 중간에 나갔다 와도 돼요. 브라우저 화면은 없어요. 나중엔 터미널에서 pilo 를 치면 앱이 열려요.
you are through when되면
The app shows Set up pilo with four steps.앱에 Set up pilo 와 단계 넷이 보여요.
if the app does not open안 되면 앱이 안 열릴 때
TERMINAL
$ pilo
03app앱Get ready준비물
Claude Code or Codex installed and signed in once, and one session opened in the app; a button does it. Each check turns green on its own.Claude Code 나 Codex 설치와 한 번 로그인, 그리고 앱에서 연 세션 하나. 세션은 버튼으로 열어요. 확인되면 저절로 초록이 돼요.
you are through when되면
Every check in the step is green.단계의 확인이 모두 초록이에요.
if neither agent is installed안 되면 에이전트가 없을 때
Install one in a terminal, sign in once, then come back to the app.터미널에서 하나 설치하고 한 번 로그인한 뒤 앱으로 돌아와요.
TERMINAL
$ curl -fsSL https://claude.ai/install.sh | bash
TERMINAL
$ brew install --cask codex
04app앱Pick your desk데스크 정하기
The desk is the one session you talk to. It reads every request and hands it to the right owner. Pick it from the sessions open in the app and press Make it the desk.데스크는 말을 거는 세션 하나예요. 요청을 모두 읽고 맞는 담당에게 넘겨요. 앱에 열린 세션 중에 골라 Make it the desk 를 눌러요.
you are through when되면
The step shows the desk and its folder.단계에 데스크와 그 폴더가 보여요.
05app앱Owners, optional담당 등록 (선택)
Each other session can own one project. Press Make it an owner, and its instruction file (CLAUDE.md or AGENTS.md) gets Pilo's rules in one marked block. The desk works alone too, so Skip is fine.나머지 세션은 프로젝트 하나씩을 맡을 수 있어요. Make it an owner 를 누르면 그 세션의 지시문 파일(CLAUDE.md 나 AGENTS.md)에 Pilo 규칙이 표시된 블록 하나로 들어가요. 데스크 혼자서도 일하니 Skip 해도 돼요.
you are through when되면
Each owner you wanted is registered, or you pressed Skip.원하는 담당이 모두 등록됐거나 Skip 을 눌렀어요.
06app앱A first request첫 요청 보내 보기
One request there and back, to see that the desk hears you and answers. Go to Work and write it in the box at the bottom, for example: tell me what you can do here.요청 하나를 보내 데스크가 듣고 답하는지 확인해요. Go to Work 를 눌러 아래 입력칸에 적어요. 예: 여기서 뭘 할 수 있는지 알려줘.
you are through when되면
The desk answers, and Finish setup takes the setup screen away. Settings keeps the switches.데스크가 답하고, Finish setup 을 누르면 설정 화면이 사라져요. 스위치는 Settings 에 남아요.
if there is no answer after two minutes안 되면 2분이 지나도 답이 없을 때
The desk's terminal may be showing a prompt of its own, such as a trust or permission question. Answer it there, or from the app's approval card, and pilo carries on.데스크 터미널에 신뢰나 권한 같은 자체 질문이 떠 있을 수 있어요. 거기서, 또는 앱의 승인 카드에서 답하면 pilo 가 이어서 진행해요.
07work screenWork 화면Say one thing, get one answer요청 한 건 넣고 답 받기
Type it in the box on Work. You do not name an agent: the desk reads the request, decides whose work it is, and hands it on. While it is out, the line under your request says who is holding it; when everything lands you get one answer, in the language you asked in.Work 화면 입력칸에 그냥 적어요. 누구에게 시킬지 안 골라요. 데스크가 읽고 누구 일인지 정해서 넘겨요. 일이 나가 있는 동안 요청 아래 줄에 누가 들고 있는지가 붙고, 다 들어오면 답이 하나로 와요. 물어본 언어로.
you are through when되면
One request, one answer, and Requests keeps every stage it went through.요청 한 줄에 답 한 줄. Requests 화면에 그 요청이 거쳐 간 단계가 남아 있어요.

The screens here are the real app against a demo desk: projects that do not exist and requests that never happened.이 문서의 화면은 실제 앱이고 데이터는 시연용이에요. 있지도 않은 프로젝트와 일어난 적 없는 요청입니다.

Everything else is in the나머지는 전부 docs문서에 있어요
